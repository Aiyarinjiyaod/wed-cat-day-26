# MeowFurniture 🐱📐

**การพัฒนาโปรแกรมประยุกต์บนเว็บร้านเฟอร์นิเจอร์แมวด้วยเทคโนโลยีความเป็นจริงเสริม**
*Web Application Development for a Cat Furniture Store Using Augmented Reality Technology*

ระบบแพลตฟอร์มพาณิชย์อิเล็กทรอนิกส์อัจฉริยะ (Intelligent E-commerce Platform) ที่บูรณาการเทคโนโลยีความเป็นจริงเสริมบนเว็บ (Web-based Augmented Reality: WebAR) ช่วยให้ลูกค้าสามารถจำลองการจัดวางเฟอร์นิเจอร์แมว (เช่น คอนโดแมว, ที่ลับเล็บ) ในพื้นที่จริงผ่านเว็บเบราว์เซอร์สมาร์ตโฟนได้ทันทีในอัตราส่วน 1:1 โดยไม่ต้องดาวน์โหลดแอปพลิเคชันเพิ่มเติม เพื่อแก้ไขปัญหาการสั่งซื้อสินค้าผิดขนาดและลดอัตราการคืนสินค้า

---

## 🚀 คุณสมบัติเด่นของระบบ (Key Features)

### 🛒 ส่วนสำหรับลูกค้า (Customer Features)
* **3D Interactive Web Viewer:** แสดงผลสินค้าในรูปแบบโมเดล 3 มิติ สามารถหมุนดูมุมมองรอบด้านแบบ 360 องศา และย่อ-ขยายเพื่อตรวจสอบรายละเอียดได้อย่างอิสระ
* **Markerless WebAR (Scale 1:1):** จำลองการจัดวางเฟอร์นิเจอร์แมวเสมือนจริงลงบนพื้นที่จริงผ่านกล้องสมาร์ตโฟน โดยอ้างอิงสัดส่วนและขนาดจริงอย่างแม่นยำ
* **E-Commerce System:** ระบบสมัครสมาชิก, จัดการตะกร้าสินค้า, สั่งซื้อสินค้าพร้อมระบบอัปโหลดรูปภาพหลักฐานการโอนเงิน (Payment Slip) และระบบติดตามสถานะคำสั่งซื้อแบบเรียลไทม์

### 📊 ส่วนสำหรับผู้ดูแลระบบ (Admin Features)
* **Admin Dashboard:** หน้าแผงควบคุมแสดงภาพรวมยอดขายรวม สถิติออเดอร์ล่าสุด และข้อมูลสินค้าขายดี
* **Product & Catalog Management:** ระบบเพิ่ม ลบ แก้ไขรายละเอียดสินค้า คลังสินค้า รวมถึงการอัปโหลดไฟล์โมเดล 3 มิติ (.glb / .usdz)
* **Order & Payment Verification:** ระบบตรวจสอบความถูกต้องของสลิปโอนเงิน อนุมัติ/ปฏิเสธคำสั่งซื้อ (ระบบตัดสต็อกอัตโนมัติ) และบันทึกหมายเลขพัสดุ (Tracking Number)

---

## 🛠️ เทคโนโลยีที่ใช้พัฒนาระบบ (Tech Stack)

* **Frontend:** Next.js (App Router), React.js, TypeScript, Tailwind CSS
* **Backend & Logic:** Next.js Serverless Functions
* **Database & ORM:** PostgreSQL (Hosted on Neon Cloud), Prisma ORM
* **3D & AR Technology:** 
  * **Blender:** สำหรับสร้าง ขึ้นรูป และปรับแต่งโครงสร้าง Polygon ของโมเดล 3 มิติให้เหมาะสมกับการแสดงผลบนเว็บ
  * **Google `<model-viewer>`.** เว็บคอมโพเนนต์มาตรฐานสำหรับแสดงผล 3D/AR รองรับ WebXR (Scene Viewer บน Android และ AR Quick Look บน iOS)
